\### 01. PRISM — LLM Security Gateway\
\
\*\*Application Security | AI Security\*\*\
\
A local-first LLM security gateway focused on identifying prompt injection attempts, protecting sensitive information, and enforcing security policies.\
\
\- Prompt injection detection\
\- Sensitive data protection\
\- Explainable risk scoring\
\- Policy-based security decisions\

\### 02. NEXUS — Network Intrusion Detection\
\
\*\*Network Security | Threat Detection\*\*\
\
A network threat detection and analysis system designed to identify suspicious network activity and provide security visibility.\
\
\- Network traffic monitoring\
\- Suspicious activity detection\
\- Intrusion detection workflows\
\- Security event analysis\
